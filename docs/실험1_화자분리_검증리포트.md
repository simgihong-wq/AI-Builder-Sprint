## 1. 실험 목적

파이프라인 1단계(캡처 → 텍스트+화자 분리)의 핵심 가설 검증:

> "Document Parse가 말풍선의 좌표를 반환하고, 그 좌표로 화자(나/상대방)를 구분할 수 있다."

"파싱 품질이 전체 품질의 상한선"(사전교육 3-5)이므로, 개발 시작 전에 이 가설이 깨지면 설계 전체를 바꿔야 함 → 최우선 검증 대상.

## 2. 검증 매트릭스 (샘플 6종)

| 플랫폼 | 라이트 | 다크 | 비고 |
|---|---|---|---|
| 당근마켓 | ✅ | ✅ | 아이패드 거래, SSD 거래 (협상 포함) |
| 번개장터 | — | ✅ ×2 | 콘서트 티켓 거래 (가격 협상), 안전결제 시스템 메시지 |
| 문자(iMessage) | ✅ | ✅ | 동일 대화 양 테마 비교, 사진 첨부 포함 |
| 카톡 | 미실시 | 미실시 | 4플랫폼×2테마 결과가 완전 일치하여 구조적으로 동일 판단, 범위에서 제외 |

## 3. 핵심 실측 결과

### 3-1. 좌/우 정렬 기준선 (전 샘플 일관)

| 플랫폼 | 왼쪽 말풍선 x_min | 오른쪽 말풍선 x_max |
|---|---|---|
| 당근 (다크/라이트) | ≈ 0.16 | ≈ 0.933 |
| 번개장터 | ≈ 0.08 | ≈ 0.91 |
| iMessage (라이트/다크) | ≈ 0.07 | ≈ 0.93 |

- 말풍선 **길이와 무관하게** 정렬 기준선 고정 (오른쪽 정렬 = x_max 고정, 왼쪽 정렬 = x_min 고정)
- 왼쪽 시작점 차이는 프로필 사진 유무 (당근 있음 0.16 / 나머지 없음 0.07~0.08)
- 라이트 vs 다크: 동일 대화 좌표 차이 **±0.002 이내** → 테마 영향 사실상 0

### 3-2. 확정된 화자 판별 규칙

```
x_max ≥ 0.88  →  내 메시지 (오른쪽 정렬)
x_min ≤ 0.20  →  상대방 메시지 (왼쪽 정렬)
둘 다 아니면   →  Solar 맥락 판별 폴백 (현재까지 해당 케이스 0건)
```

### 3-3. 텍스트 추출 품질

- 구어체·이모티콘·줄임말 전부 정확: "ㅋㅋㅋㅋ 고마워요~", "잇나용", "안되고ㅜ내일됩니다ㅜ"
- 금액·계좌번호·날짜 정확 추출: "370,000원", "농협 3511094710813", "2026/01/28 15:10"
- 사소한 이슈: 줄바꿈 병합("안녕하세요아직"), 헤더 영역 텍스트 병합("상상엽이형") → 필터 구간이라 무해

## 4. 확정된 후처리 파이프라인 (Day 1 구현 스펙)

```
① y좌표 기준 재정렬        ← JSON 요소 순서가 화면 순서와 불일치하는 사례 발견 (필수!)
② 타임스탬프 제거          ← 정규식 `(오전|오후) \d{1,2}:\d{2}` (폰트크기 필터는 플랫폼별로 흔들림: 당근 14px, 번개 16px)
③ 노이즈 블록 제거         ← 한글·숫자 없는 2글자 이하 블록 (아이콘: T, ₩, V, 个, [c]+[c])
④ 상/하단 UI 제거          ← y < 0.12 (헤더) / y > 0.88 (입력창 — 미전송 입력 텍스트도 잡히는 것 확인됨)
⑤ 시스템 메시지 분류       ← 광폭 블록(x 스팬 > 0.8) 또는 고정 문구("안심결제로 안전하게", "거래 예약을 했어요")
                            ※ 버리지 않음: "결제 완료·거래방법·금액"은 플랫폼이 보증하는 최고 신뢰도 확정 정보
⑥ 화자 배정                ← 3-2 규칙 적용
⑦ figure(사진 첨부)        ← 화자 배정 없이 "사진 공유됨" 이벤트로만 기록 (제품 상태 확인 체크 항목에 활용)
```

## 5. 부수 발견 (예상 못 했던 수확)

**① 계좌번호가 완벽 추출됨 → 개인정보 마스킹 필요성 실증**
- 실제 계좌번호가 그대로 뽑힘 → "업로드 즉시 정규식 마스킹" 단계를 파이프라인 맨 앞에 두는 설계가 이론이 아닌 실측 근거를 확보
- ⚠️ 해당 JSON/캡처는 외부 공유 금지, 데모용은 가짜 번호로 재제작 필수

**② 시스템 메시지 = 노이즈가 아니라 확정 정보**
- 번개장터 결제 카드에서 "정산 예정 금액 291,400원 / 거래방법: 일반택배(선불)" 추출
- 약속 카드에서 "✔ 안전결제 완료 (플랫폼 확인)" 별도 등급으로 표시 가능 → 서비스 가치 상승

**③ 리스크 탐지용 골드 샘플 2종 확보**
- 샘플 A (당근): 구매자의 안심결제 문의에 답변 회피 + "급전이 필요해서" 긴급성 압박 + 직거래 유도
- 샘플 B (문자): 대면 거래 거부 + 기프트콘/계좌이체 선입금 유도 + 계좌번호 즉시 제시
- → 단순 누락 탐지를 넘어 "대화 흐름 속 위험 신호"를 잡는 데모의 핵심 재료 (번호는 교체 후 사용)

**④ 협상 흐름 샘플 확보**
- 번개(티켓): 31만 → 수수료로 32 제안 → 31 합의 / 당근(SSD): 6만 정가 → 5.5 제안 → 5.8 합의
- → Information Extract A/B 실험(실험 ②)에서 "최종 합의 가격" 추출 난이도 테스트로 사용
