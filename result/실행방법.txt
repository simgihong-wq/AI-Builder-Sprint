혹시 실행 방법 (제출 결과물)
==========================

0) 원클릭 실행 (권장)
   같은 폴더의 실행.bat 더블클릭.
   백엔드 서버가 새 창으로 뜨고, 몇 초 뒤 자동으로 이 결과물 화면이 열린다.
   (.venv, .env가 backend/에 이미 준비돼 있어야 함 — 최초 1회는 아래 1)번 참고)

   원클릭이 안 되면 아래 1)~2)번을 수동으로 따라한다.

1) 백엔드 서버 켜기
   cd backend
   pip install -r requirements.txt   (최초 1회)
   cp .env.example .env              (최초 1회, UPSTAGE_API_KEY 입력)
   python app.py

   -> http://127.0.0.1:5000 에서 서버가 뜬다. (PORT 환경변수로 포트 변경 가능)
   -> http://127.0.0.1:5000/health 로 정상 기동 확인 가능.

2) 결과 화면 열기
   result/index.html 파일을 브라우저로 더블클릭해서 열면 된다.
   (별도 서버 필요 없음, 파일을 그냥 열면 됨)

   백엔드 주소는 http://127.0.0.1:5000 으로 코드에 고정돼 있다(화면에는 안 보임).
   포트를 바꿔서 서버를 켰다면 result/index.html의 #api-base 기본값을 직접 고칠 것.

3) 테스트 방법 (둘 중 아무거나)
   - 텍스트 붙여넣기 탭: 아무 대화나 붙여넣고 "분석 시작하기"
     (나: / 상대방: 접두어를 붙이면 화자 인식이 더 정확함)
   - 캡처 올리기 탭: 같은 폴더의 sample_chat.png를 끌어다 놓고 "분석 시작하기"
     (가짜 대화로 만든 샘플 캡처 — 실제 파이프라인 검증 완료된 이미지)

4) 결과 화면
   분석이 끝나면 자동으로 "결과 요약 -> 체크리스트 -> 약속 카드" 화면으로
   넘어간다. frontend/ 파일은 전혀 건드리지 않고 디자인만 복사해서 만든
   독립 페이지라, frontend/ 실제 연결 작업과는 무관하게 지금 바로 테스트
   가능하다.

문제 생기면
-----------
- "백엔드에 연결하지 못했어요" / Failed to fetch
  -> 1)번 서버가 꺼져 있거나 포트가 다른 경우. 서버 다시 켜고 result/index.html의
     #api-base 기본값이 실제 서버 주소와 맞는지 확인.
  -> 서버는 떠 있는데도 계속 이 에러가 나면, 일부 Windows 환경에서
     "localhost"가 IPv6(::1)로 먼저 풀리고 Flask는 IPv4만 듣고 있어서
     타임아웃나는 경우다(실측 확인됨). 그래서 기본값을 127.0.0.1로 고정해둠 —
     그런데도 안 되면 방화벽/보안 소프트웨어가 로컬 접속을 막고 있는지 확인.
- 이미지 업로드가 이상하게 나옴
  -> 실제 카톡/당근 캡처가 아니라 sample_chat.png(합성 이미지)로 먼저
     테스트해볼 것. 실제 캡처 샘플은 재윤 test-data/ 나오면 추가 검증 예정.
